## 首次审查发现与保留边界

1. Git 历史仍含备份脚本旧的本机目录文字；两张 docs 截图显示账号昵称。它们不是密码，但当前仓库并非完全匿名。9 次提交使用 GitHub noreply 邮箱。没有改写历史或擅自修改作者身份。
2. 现有 docs 报告截图还有布局失真，不建议作为新版本的主要展示图；这是展示质量问题，不是凭据泄漏。材料包截图中可见 E2E 账号名。
3. 主应用开发 JWT 密钥、开发 AES Key 和靶场签名密钥是公开默认值。公开源码可以保留，正式运行必须配置独立密钥。主应用生产 JWT 校验目前只拒绝空值，未拒绝示例占位字符串；不要原样复制示例值上线。
4. `backend/bootstrap_e2e.py` 会创建或重设固定测试账号及管理员，且没有生产环境保护。它不是自动启动路径，但不得对正式数据库执行。
5. 备份脚本仍是普通文件复制。运行中的 SQLite/WAL 一致备份和备份恢复验证不在本次脱敏修复范围；备份敏感程度与原数据库相同，不应上传。
6. 演示靶场保留故意漏洞和公开账号，仅用于本机测试，不能作为公网业务服务发布。
